# Tools - Control & Optimization Utilities

This section provides utility scripts for control algorithms and optimization methods.

## Contents

- **cem_optimizer.py** - Cross-Entropy Method implementation
- **ddp_controller.py** - Differential Dynamic Programming
- **mpc_planner.py** - Model Predictive Control
- Other control utilities and helpers

## Quick Start

```bash
python cem_optimizer.py
```

## Available Tools

### Cross-Entropy Method (CEM)
- Sample-based optimization
- Black-box optimization
- Used in policy search

### Differential Dynamic Programming (DDP)
- Trajectory optimization
- Local optimal control
- Efficient computation

### Model Predictive Control (MPC)
- Receding horizon control
- Constraint handling
- Real-time capable
