# Demonstrations

This directory contains organized demonstrations and tutorials for MuJoCo-Testing.

## Structure

Each subdirectory (01-08) contains a focused set of examples:

- **01-fundamentals**: Physics basics and foundational concepts
- **02-visualization**: Interactive GUI demonstrations
- **03-robotics-arms**: Robotic arm examples
- **04-locomotion**: Legged robot locomotion
- **05-manipulation**: Pick and place and object manipulation
- **06-learning-rl**: Reinforcement learning and optimal control
- **07-tools**: Optimization and control utilities
- **08-testing**: Integration tests and validation

## Getting Started

1. Start with **01-fundamentals** if you're new
2. Move to **02-visualization** to see interactive examples
3. Explore specific domains (arms, locomotion, manipulation)
4. Try **06-learning-rl** to train agents
5. Use **07-tools** in your own projects

## Running a Demo

Each directory has a README.md with specific instructions. Generally:

```bash
cd XX-category/
python script_name.py
```
