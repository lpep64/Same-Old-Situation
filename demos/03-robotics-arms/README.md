# Robotics - Robotic Arms

This section contains demonstrations of robotic arm systems including Franka, UR, and Niryo robots.

## Contents

- **franka_panda.py** - Franka Emika Panda arm demonstrations
- **ur_robot.py** - Universal Robots UR series
- **niryo_arm.py** - Niryo One robotic arm
- Kinematics and inverse kinematics examples
- Force control demonstrations

## Quick Start

```bash
python franka_panda.py
```

## Featured Robots

- Franka Emika Panda (7-DOF collaborative arm)
- UR5e / UR10e (Industrial arms)
- Niryo One (Educational arm)

## Topics

- Forward and inverse kinematics
- Trajectory planning
- Force/impedance control
- Human-robot interaction safety
