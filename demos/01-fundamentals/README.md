# Fundamentals - Basic Physics & Concepts

This section covers fundamental physics concepts and basic MuJoCo simulations.

## Contents

- **basic_tests.py** - Basic physics simulation tests (falling bodies, collisions)
- **pendulum.py** - Pendulum dynamics and control examples
- **collision_detection.py** - Collision handling demonstrations
- Other physics fundamentals

## Quick Start

```bash
python basic_tests.py
```

## Learning Objectives

After exploring these examples, you should understand:
- Basic physics simulation principles
- How to define bodies and joints in MuJoCo
- Gravity and collision physics
- Control of simple systems

## Prerequisites

- Python 3.8+
- MuJoCo installed (`pip install mujoco`)
- Basic understanding of physics
