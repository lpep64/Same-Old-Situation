# Learning & Control - RL and Optimization

This section demonstrates reinforcement learning and optimal control.

## Contents

- **hanoi_solver.py** - Tower of Hanoi RL solver
- **policy_training.py** - Reinforcement learning training
- **control_optimization.py** - Optimal control methods
- Model-based and model-free algorithms

## Quick Start

```bash
python hanoi_solver.py
```

## Topics

- Reinforcement learning (DQN, PPO, A3C)
- Policy optimization
- Model-based control
- Cross-entropy method
- Differential dynamic programming
- Imitation learning

## Training

Training RL agents requires computation. Expected times:
- Hanoi solver: ~5-10 minutes
- Manipulation tasks: ~30-60 minutes
- Complex tasks: 1+ hours
